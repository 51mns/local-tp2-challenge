# Local TP2：証明・反例・誤りの指摘を募集

**全木では未証明・未反証。** AIと研究してきた不等式について、別の方法での証明、正確な反例、過去の部分証明の誤りを募集する。

[English](README.md) · [厳密な問題定義](PROBLEM.md) · [到達点](STATUS.md) · [失敗した手法](FAILED_ROUTES.md)

## 問題

根は

$$
(A,C,B)=(1,2x^2+6x+5,x+2).
$$

各状態で

$$
\ell=3(x+1)AC-x(A+C)-B,\qquad
r=3(x+1)BC-x(B+C)-A
$$

を計算する。左への移動 L は $(A,\ell,C)$、右への移動 R は $(C,r,B)$ に置き換える操作。任意の有限個の L/R を、左から順に適用する。

その状態からの二つの子を**次数順**に並べて、小さい方を U、大きい方を V とする。

$$
S=U-C,\quad D=V-U,\quad H(P)_n=[q^n]P(q+q^{-1})
$$

としたとき、すべての状態と $0\le n\le\deg S$ について

$$
\boxed{H(S)_nH(D)_{n+1}-H(S)_{n+1}H(D)_n>0}
$$

かどうかを問う。支持外の係数は0。**等号0も、厳密な不等式への反例になる。** L側が必ず小さい子とは限らない。末端の添字も省略しない。

根の検算値は `H(S)=[40,32,16,4]`、`H(D)=[164,138,80,30,6]`、小行列式は `[272,352,160,24]`。

## ここまでの結果

**有限計算：** 2026年10月7日の記録では、16,677状態・10,176,120個の対象小行列式はすべて正だった。完全列挙は深さ13まで。それより深い経路は選択的な探索で、最長1,024までを全列挙したわけではない。この公開作業で全探索をやり直したという主張でもない。

**部分証明：** 全 $L^mR^kL^j$ の内部証明記録と、一部の4ランを含む無限族の証明候補を公開している。別モデル・数学者による外部査読やLean形式検証は済んでいない。資料内の `PROVED_INTERNAL` は当時の内部ラベルで、外部に確立した定理と同義ではない。過去の証明も疑って検証してほしい。

**失敗した方法：** 最大係数で一律に下界を抑える保存則候補は、正準状態で破れた。ただし、そのとき元のLocal TP2が破れたわけではない。この区別を必ず保つ。

## 再現

**Mac：ターミナルまたはVS Code内蔵ターミナル。Windows：PowerShell。リポジトリ直下で実行する。** Windowsで必要なら `python3` を `python` に置き換える。

```bash
python3 -m unittest discover -s tests -v
python3 check.py --word LRL
python3 check.py --depth 6
```

順に、実装のテスト、指定経路の全添字の検算、深さ6までの完全列挙。標準Pythonだけを使う。計算の成功は全木証明ではない。

## 外部AI・研究者にお願いしたいこと

既存の方針を引き継ぐ必要はない。新しい証明、正確な経路と添字を伴う反例、部分証明の誤り、全木へつながる一般補題を歓迎する。反例の場合は四係数と積の差を、証明の場合は全仮定・依存補題・有限検算から無限範囲へ進む根拠を明示してほしい。
