# Local TP2：中央の R の回数を任意にした証明

**主状態：PROVED_INTERNAL。**

今回の続きで、前回の `L^m R^2 L^ell` から、

\[
\boxed{L^mR^kL^\ell\quad(m,k,\ell\ge0)}
\]

のすべてに対して、元の厳密な Local TP2 を証明した。3つの指数には上限を置いていない。支持の最後の係数比較も含む。

これは、リポジトリ内の既証明の基礎補題と、新しい補題・厳密な有限証明書を組み合わせた内部検証済みの数学的証明である。任意の経路全体に対する Local TP2 は引き続き未解決であり、Lean 等による形式検証や外部の独立再現を主張するものではない。

完全な証明は [GENERIC_ARBITRARY_K_CLOSURE.md](arbk_root/GENERIC_ARBITRARY_K_CLOSURE.md)、無限パラメータを覆う評価の詳細は [SCALAR_COVERAGE.md](arbk_root/SCALAR_COVERAGE.md) にある。

## 1. 元の目標をそのまま証明した

根を

\[
(A,C,B)=(1,2x^2+6x+5,x+2),\qquad y=x+1
\]

とし、子を作る元の変換式を

\[
L=3yAC-x(A+C)-B,\qquad
R=3yCB-x(C+B)-A
\]

とする。ある頂点の2つの子を次数の小さい順に (U,V) と書き、

\[
S=U-C,\qquad D=V-U,\qquad
H(P)_n=[q^n]P(q+q^{-1})
\]

とする。今回の結論は、対象となるすべての経路で

\[
H(S)_nH(D)_{n+1}-H(S)_{n+1}H(D)_n>0
\qquad(0\le n\le\deg S)
\]

が成立する、という元の主張である。補助的な正値性だけで止まっていない。

## 2. 今回の決め手

### 必要な中点の関係を使い、補正を小さくした

新しい右連続長 (k) の後で左へ進む際の seed を (A,B)、固定された trace を (t) と書くと、単一のスペクトル因子は

\[
L_r=A(t-r)+B
\]

になる。異なる2つの因子を混ぜる際に必要なのは、実際の中点

\[
c=\frac{r+s}{2},\qquad h=\frac{r-s}{2}
\]

に対する

\[
\begin{aligned}
H_{r,s}
&=A(t-r)(t-s)+B(t-c)\\
&=(t-c)L_c-h^2A
\end{aligned}
\]

である。先に (L_c) の核を証明しておけば、右辺は扱える積から小さい項を引く形になる。(r,s\in[-2,2]) なので (h^2\le4)。trace の中央係数の下界を (s_0) とすれば、減算項は積の (4/s_0^2) 以下に押さえられる。

この二乗の減衰が、(k) を任意にする評価を閉じるうえで大きかった。独立な第三パラメータを含む、必要以上に広い条件を証明する負担もなくなった。

### 正規化した余裕から、すべての minor をまとめて支配した

Fourier 半行 (h_n=H(P)_n) に対し

\[
\delta_n(h)=h_n^2-h_{n-1}h_{n+1}-h_{n+1}^2+h_nh_{n+2},
\qquad
\eta(P)=\min_n\frac{\delta_n(h)}{h_n^2}
\]

を使った。新しく整理した補題により、folded cone に属する (F) のすべての順序付き minor について

\[
\det K_F[I,J]\ge\frac{\eta(F)}4
K_F(i,a)K_F(j,b)
\]

が成り立つ。したがって、非負の参照多項式 (B) に対して

\[
F\ge cB,\qquad \eta(F)c^2\ge16
\]

を示せば、無限の核のすべての必要な minor で

\[
\det K_F\ge4\det K_B
\]

が従う。参照行 (B) 自体に cone 性を要求する必要はない。これは有限サイズの核を走査した結論ではなく、隣接 minor と交差比の積から得る一般補題である。

### 元の seed の正しい再帰と、大きさの増加を使った

旧 one-turn の中心を (1+yZ_j)、固定端点を (Y=1+yT_m) とすると、新しい seed は厳密に

\[
A=Z_k-T_m,\qquad B=Z_{k-2}-T_m
\]

になる。(a_j=Z_j-T_m)、(\tau=3yY-x) と置くと

\[
a_{j+1}=\tau a_j-a_{j-1}+Y(3Y-2)
\]

という正の表示に展開できる再帰を得た。そこから

\[
A\ge(\tau-1)^2B
\]

が従う。また、(d=m+2)、(M=\tau(2)-2) とすると、二つの固定補正を共通に支配する係数として

\[
c\ge\frac{9M^{2k}}{512(2dk-3)^2}
\]

を取れる。この指数的な増加を、正規化した defect の下界と組み合わせた。

別の補助定理として、すべての (m\ge0,j\ge1) で

\[
\delta_n(Z_j-T_m)\ge\tfrac12\delta_n(Z_j)
\]

と、その (y) 倍版も証明・監査できた。今後 (Z_j) の評価を改善した場合にも、その改善を seed に運ぶために使える。

## 3. 無限個のパラメータをどう覆ったか

最後の左連続長 (\ell) は、正の Jacobi-resolvent 展開と既存の有限出発点からの延長定理で一括して扱う。その際、混合項の符号と重みの二乗を明示的に残し、正の多項式の和が自動的に cone に入るとは仮定していない。

残る (m,k) は次のように分けた。

| (m) | 解析的評価が全ての (k) に適用できる開始点 | それより小さい (k\ge3) |
|---|---:|---|
| 0 | (k\ge21) | (3\le k\le20) を厳密証明書で処理 |
| 1 | (k\ge11) | (3\le k\le10) を厳密証明書で処理 |
| 2 | (k\ge6) | (3\le k\le5) を厳密証明書で処理 |
| 3 | (k\ge5) | (k=3,4) を厳密証明書で処理 |
| 4 | (k\ge4) | (k=3) を厳密証明書で処理 |
| 5 | (k\ge5) | (k=3,4) を厳密証明書で処理 |
| 6〜69 | (k\ge3) | 追加の出発点なし |
| 70以上 | (k\ge3) を (m) についても一括処理 | 追加の出発点なし |

有限証明書を必要とする出発点は合計34個である。各出発点で証明する条件自体が、すべての (\ell\ge1) に対する結論を与える。

各固定 (m) の無限の (k) の範囲では、必要な量の隣接する (k) 間の比が、正の定数と単調増加する一次式の比の積になる。開始点で比が1より大きいことを厳密な有理数で確認し、その後は単調性で証明した。(m\ge70) についても、角 ((m,k)=(70,3)) と同様の比の単調性で全範囲を覆った。

(k=0,1,2) と (\ell=0) は、固定した既存の証明を使う。新しい証明では最後の支持指数も確認し、(a=dk+1)、(N=\ell\ge1) に対して

\[
\deg D-\deg S=a(N-1)+d>0
\]

が成立するため、末端比較が抜け落ちない。

## 4. 検証記録

すべての判断に整数または厳密な有理数を用いた。実数パラメータは Bernstein 多項式の全係数によって区間・箱全体を覆っている。補間に使う有限個の点は多項式を厳密に復元するためのもので、点をサンプルして正値性を推測する方法ではない。

| 検証対象 | 内容 | 別実装での照合 |
|---|---:|---|
| 34個の出発点から全左連続長を扱う条件 | 3,282個の正の Bernstein 係数 | 全係数・閾値・添字が一致 |
| 単一・中点核の正値性 | 51,804個の正の Bernstein 係数 | 全係数が一致 |
| 中点核の参照 minor 支配 | 42,246個の正の比較係数 | 全係数が一致 |
| (m=0) の根ペアブロックと残余 | 223,484個の tensor 係数 | 全最小値・完全 digest が一致 |
| (m=1,2,3,4) のブロックと残余 | 102,060個の圧縮係数が4,021,860個の全 tensor 係数を表す | 全展開した値・分母・対称性の反復まで一致 |
| 旧 (m=0,\ldots,69) の区間評価 | 38,745組の defect／square 係数 | 全境界値・digest が一致 |
| seed の減算補題 | 122組、16,048個の整数余裕 | 全値が一致 |
| 無限範囲を覆う scalar 条件 | 70個の固定 (m) と解析的な (m\ge70) の範囲 | 全値・連続比・単調性を確認 |

各監査は著者実装を import せず、通常の (x) 多項式と Laurent 半行、直接展開と補間など、異なる構成から再計算した。同じ共有研究セッション内での独立実装・数学的確認として記録している。

保存用の一式は [reproduce.py](reproduce.py) で、12個の作成・監査プログラムを依存順に再実行する。大きい証明書は可逆圧縮し、元の全データの SHA-256 も保存している。再実行は一時作業領域で行い、保存済みの証明書と再生成した全12結果の hash を比較する。[README.md](README.md) と [REPLAY_RESULT.json](REPLAY_RESULT.json) に実行方法と結果がある。

## 5. openai/math との関係と残る問題

最初の調査で参考になったのは、正の表現を先に作り、それが元の比較に一致することを示すという証明設計と、混合項・相殺項を明示的に扱う方針だった。今回の直接の証明は、それを AIMath の folded kernel、元の mutation、Jacobi 展開の上で進め、中点の減算表示と正規化した minor 下界を新たに組み合わせたものとなる。外部の資料の定理がそのまま Local TP2 を解決したという位置づけではない。

外部資料は `openai/math` の固定 commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`、直前の私有研究状態は `f1bf528c9064e11f79795a581b6a4bc15f0efbe1` を基準にした。[DEPENDENCIES.md](DEPENDENCIES.md) に詳細を示す。

未解決なのは、さらに方向転換を重ねた任意の canonical path へ、この量的な評価と係数支配を保ちながら進める部分である。今回の定理は (L^mR^kL^\ell) という無限族を完全に扱う。全木の Local TP2 を証明したとはしていない。
