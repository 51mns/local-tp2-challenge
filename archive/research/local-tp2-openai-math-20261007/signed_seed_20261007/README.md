# Local TP2：符号付き seed による継続

**全木の Local TP2 は未証明。今回の主状態は `PROOF_CANDIDATE`。**

保存済み3ラン証明の続きを点検し、個々の4ランを増やす前に、延長条件の符号制限を修正した。従来の `B>=0` は、一歩進むと `B_next=-A` になるため、そのまま共通不変量にはできない。

## 今回組み立てた証明

**全木共通の補助定理。** どの正準頂点でも、左右どちらを次の固定方向に選んでも、補助量は

`A+B>=0`, `A-B>=0`, `0<=|B|<=A`

を通常の x 係数ごとに満たす。B 自体は正・負・零のいずれも許す。根からの帰納法と引き算のない恒等式で示したもので、有限検算からの推測ではない。この補助定理だけでは TP2 は出ない。

**符号付き seed の延長定理。** B が負でも、正のスペクトル混合の中に符号を残せば、必要な混合小行列式を制御できる。変更すべき質量比と単調性の論理も明示した。正性が必要な参照行は |B| であり、その行自体の cone 性は要求しない。実際の中点だけを使うので、余分な第三パラメータも不要。

**元の厳密な Local TP2 を結論とする二つの無限族。**

- `LRL R^N`, すべての整数 `N>=0`。
- `RLR L^N`, すべての整数 `N>=0`。

最初の族は N>=1 で4ランの経路を含む。有限の出発点だけを検査して N を外挿したわけではない。固定次数の区間・中点条件を厳密証明書で確認し、延長定理が任意の N と支持の末端を処理する。ただし、これは任意の `L^aR^bL^cR^d` の証明ではない。

証明全文と全仮定は `THEOREM.md`。既存の folded-kernel 補題を使い、今回変更した符号の扱いと無限回への移行を明記した。独立した数学者・別AIによる新規査読は実施していない。同じモデルが構成した別方式の実装を比較した段階なので、正規の独立再現状態に昇格させていない。既存3ラン証明の全証明書を再監査したという主張もしない。

## 検算

通常の x 多項式と厳密補間を用いる作成側、Laurent 多項式とパラメータの記号展開を用いる検算側を分離した。検算側は作成側のモジュールも期待結果も読み込まない。計算後、別の比較処理が全配列を照合する。

`LRL R^N` で1,566項、`RLR L^N` で1,821項、合計3,387項の証明書・閾値・補正余裕が完全一致。整数と Fraction のみを使う。5個の contract test には、根の再構成、一般恒等式の有限回帰検査、末端次数、符号誤りの拒否、補間点だけでは正値性を判定しない負の対照例を含めた。

**MacのVS Code内蔵ターミナルで、このフォルダを開いて実行：**

```bash
python3 reproduce.py
```

標準ライブラリだけで2方式×2入力とテストを一時フォルダで再実行し、全配列と保存済みハッシュを比較する。再生成した全証明書は `replay_output/` に置き、固定ソースを変更しない。保存時の結果は `RUN_REPORT.json`。

## 効率を優先した次の課題

次に必要なのは例の追加ではなく、任意の次の方向転換でも、trace の cone 性、符号付き単一・中点核、四つの初期比較、補正を吸収する余裕を維持する定理である。今回の全木補題により seed の符号・係数非負性は毎回証明し直す必要がなくなったが、残りの条件の保存は未証明。

小さい固定端点では十分条件の質量下界が失敗しても Local TP2 自体は成立しうる。この証明書の失敗を予想の反例として扱わない。4ランが一例通ったことから全4ランや全木へ飛躍せず、保存の核心を先に検査する。
