# Local TP2：全木の結合関係を残した保存則の点検

**全木の Local TP2 は未証明。今回の主状態は PROOF_CANDIDATE。証明済み経路の範囲は増えていない。**

今回は、経路の例を追加するより先に、単一の余裕を保つ近道と、正準状態の結合関係を残す方法を調べた。前者には厳密な反例が出た。後者では両方の子に対応する引き算のない更新式と、全木共通のより強い補正項評価を導けた。ただし、係数小行列式の正性を保つ帰納則までは得られていない。

## 1. 三つの非負多項式による、両更新の正確な表現

次数の小さい端点を X、大きい端点を Y、中心を C、逆変異で戻る多項式を T とし、y=x+1 と置く。

    u=(X-1)/y,  e=(Y-X)/y,  Q=(Y-T)/y,
    g=2x+1+3y²u,  t=g+2,
    kappa=1+4yu+3y²u²,
    A=Q+g e+kappa.

根は (u,e,Q)=(0,1,1)。次の二つの更新で正準木全体を生成できる。

    小さい端点を残す: (u,e,Q) -> (u,A+e,A)
    大きい端点を残す: (u,e,Q) -> (u+e,A,A+e)

どちらにも引き算がない。元の左右の選択を次数順に呼び直したもので、特定のラン数に限定しない。

さらに、元の Fricke 方程式が要求する関係は

    A Q = g e² + 2kappa e + 3u(1+yu)²

となり、この関係の両辺の差は二つの更新でそのまま保存される。既知の Fricke 関係をこの座標に書き直した結果であり、新規性は主張しない。

**これは「代数的な条件が両更新で保たれる」という結果であって、「求める Fourier 小行列式が両更新で正になる」という結果ではない。**

## 2. 負の補正項を、全木で以前より強く抑えられる

z=(T-1)/y=u+e-Q は、根で0、二つの更新後にはそれぞれ u+e と u になる。したがって全木で非負。

    A-(t-1)Q = 1+(2x+3)u+(t-2)z >=0

より、以前の Q<=A だけでなく、A>=(t-1)Q が係数ごとに成立する。任意の選択方向でも、補助量 B が負なら同様に a>=(t-1)|B| が成立する。

nu=H(t)_0 とすると、スペクトル区間 r∈[-2,2] 全体で

    H(|B|)_n <= H(a(t-r))_n / ((nu-1)(nu-2))

を得る。以前の単純な上界 1/(nu-2) より、さらに nu-1 の因子だけ小さくできた。

この改善は正準の全状態・負の B に成立する。ただし、比較元の核が必要な形の正性を持つことまでは保証しない。その形の条件と初期の係数比較を両更新で証明する部分が、依然として残る。

## 3. 使えない近道を二つ、具体的に確認した

**正性の余裕を「次数の二乗」で補正し、その最小値だけを保存する案は偽。**

    F=3+44x+30x²+3x³,  G=x+2

はどちらも厳密な folded cone に入り、yF、yG も入る。それでも、正規化した余裕 eta に対し

    min(deg(F)² eta(F), deg(G)² eta(G)) = 1/2
    deg(FG)² eta(FG) = 767/1682 < 1/2

となる。これは今回試した強化案への反例で、既存の弱い積の評価や Local TP2 自体を反証していない。

**引き算のない座標・補正の小ささ・次数関係だけでも足りない。** u=0、e=x+23、Q=x+1 とすると、それらの条件は満たすが Fricke 関係は満たさず、元の中央小行列式は -3176 になる。この入力は非正準で、既存定理の核条件も満たさない。正準の反例として扱ってはいけない。

## 4. 検証と限界

- 任意の x,u,e,Q に関する23個の恒等式を、整数係数の記号展開で完全に照合した。点を代入して推測したものではない。
- 正の三変数更新による実装と、元の再帰を Laurent 多項式で計算する別実装を比較した。255状態、13,120個の元の小行列式、382個の負の補助量の上界チェック、二つの反例が一致した。
- 全木の補助定理の根拠は証明本文の帰納法。有限個の正例は実装の回帰検査であり、全木の Local TP2 証明ではない。

同じモデルが作った別実装による検算。別の研究者・別AIの査読や、Lean による形式検証は実施していない。以前の全3ラン証明を再監査したという意味でもない。
