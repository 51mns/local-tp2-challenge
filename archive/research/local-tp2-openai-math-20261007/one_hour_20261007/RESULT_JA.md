2026-10-07。対象は private `51mns/AIMath`。

**主判定：`PROVED_INTERNAL`。** 既存の基礎補題を前提に、次の無限族について、元の厳密な Local TP2 の不等式まで証明を組み立てた。

\[
\boxed{L^mR^2L^\ell\quad\text{の全ての }m,\ell\ge0.}
\]

これは今回の追加検討で、既存の研究ブランチの証明範囲を拡張する結果である。任意の word に対する全木の Local TP2 は、引き続き未証明。既存の基礎定理への依存、証明書を使う有限部分、解析的に処理する無限部分を、本文で区別している。世界的な新規性、外部査読、証明支援系による形式検証は評価していない。

完全な証明は [UNIFORM_RAY_CLOSURE.md](hour_root/UNIFORM_RAY_CLOSURE.md)。数学的な別レビューは [AUDIT_UNIFORM_RAY.md](hour_invariant/AUDIT_UNIFORM_RAY.md) と [UNIFORM_RAY_INDEPENDENT_AUDIT.md](hour_transport/UNIFORM_RAY_INDEPENDENT_AUDIT.md) にある。

## 2. 何を証明したのか

\(y=x+1\) とし、正準根を

\[
(A,C,B)=(1,\,2x^2+6x+5,\,x+2)
\]

とする。子は元のリポジトリと同じ変異

\[
L=3yAC-x(A+C)-B,\qquad R=3yCB-x(C+B)-A
\]

で作る。二つの子を次数の小さい順に \(U,V\) と並べ、

\[
S=U-C,\qquad D=V-U,\qquad H(P)_n=[q^n]P(q+q^{-1})
\]

と置いたとき、示したのは

\[
\boxed{H(S)_nH(D)_{n+1}-H(S)_{n+1}H(D)_n>0
\quad(0\le n\le\deg S).}
\]

通常の係数正性や補助核の正性だけで止めず、この元の小行列式に戻している。次数外の係数は0とし、最後の \(n=\deg S\) も含めた。

## 3. 証明の中心となった構成

### 元の変異を、固定した二つの初期多項式へ戻す

\(L^mR^2\) の状態を \((X,C_0,Y)\) とし、以後の左移動で保たれる端点を \(X\) とする。

\[
t=3yX-x,\qquad
A=(C_0-Y)/y,\qquad
B=(tY-xX-C_0-Y)/y.
\]

これらは元の変異から導いた恒等式で、別の近似モデルではない。Chebyshev 多項式 \(v_N=U_N(t/2)\)、その和 \(R_N=\sum_{j=0}^Nv_j\) を使うと、全ての左移動回数 \(N\) を

\[
q_N=y(Av_N+Bv_{N-1}),\qquad Z_N=AR_N+BR_{N-1}
\]

で表せる。以後の中心は \(C_N=Y+yZ_N\) となる。

### 混合項も含めて正性を確保する

必要なのは、各因子が正であることに加え、和を取ったときに出る混合小行列式の制御である。そのため、全ての実数 \(r,s,c\in[-2,2]\) に対して

\[
L_r=A(t-r)+B,
\qquad H_{r,s,c}=A(t-r)(t-s)+B(t-c)
\]

と、その \(y\) 倍の核を調べた。ここでは全パラメータ区間・立方体を扱う。有限個の根や格子点を試すだけでは、後続の任意の長さを正当化できないためである。

正の Jacobi 分解で現れる二つの項の混合小行列式を、その中点の小行列式と固定した \(B\) の小行列式へ分解する。中点が後者を十分な倍率で上回ることを証明し、和全体に正性を運べるようにした。

この段階の全 \(m\) の証明は [all_m_mixed_transport.md](hour_transport/all_m_mixed_transport.md)、初期多項式の一様評価は [UNIFORM_SEED_STRENGTH.md](hour_quantum/UNIFORM_SEED_STRENGTH.md) にある。

### 正性の余裕を、補正項の大きさと比較する

半行 \(h\) の正性の余裕を

\[
\delta_n(h)=h_n^2-h_{n-1}h_{n+1}-h_{n+1}^2+h_nh_{n+2},
\qquad \eta(h)=\min_n\frac{\delta_n(h)}{h_n^2}
\]

で測る。今回はこの余裕の下界と、残る補正項の係数上界を同時に追跡した。

\(m\) が大きい範囲では、主要項が補正項を上回る倍率の増加が、正性の余裕の損失を上回る。その関係を厳密な有理数の不等式にした結果、\(m\ge77\) を一括して処理できた。

外側の長さ \(N\) についても、正の重み \(\lambda_i\) を平方した項を落とさず、

\[
\sum_i\lambda_i^2\ge\frac1N,\qquad 2^{N-1}\ge N
\]

を使って、全ての \(N\ge1\) に共通の余裕を得ている。この点が、有限走査から無限族へ飛躍していないことの要所である。

### 元の二つの差分を挟む

\(p=x+2\)、\(\Pi=Xp\) として、正確な補正付きの比較を閉じると、

\[
S_N\le_{\rm lr}JZ_N
<_{\rm lr}\Pi M_N
\le_{\rm lr}E_NM_N=D_N
\]

が得られる。中央の比較が必要な全添字で厳密なので、元の Local TP2 が従う。

\(N=0\) は端点の次数順が違うため、無理に同じ式を当てはめず、既存の \(L^mR^k\) 定理の \(k=2\) を使う。\(N\ge1\) の次数差も

\[
\deg D_N-\deg S_N=(2m+5)N-m-3\ge m+2>0
\]

と確認でき、最後の小行列式にも正の係数が残る。

## 4. 有限証明と無限証明の境界

| 部分 | 有限部分 | 無限部分を覆う理由 |
|---|---|---|
| 新しい初期多項式 \(A,yA\) | \(0\le m\le28\) の全支持添字 | \(m\ge29\) は積の強度と減算補題 |
| 既存の初期式 \(a_X,ya_X\) の正規化評価 | \(0\le m\le390\) | \(m\ge391\) は既存の一様評価から導出 |
| 新しい単一因子・中点の全パラメータ箱 | \(0\le m\le53\) | \(m\ge54\) は正規化した余裕が補正を上回る |
| 元の目標に戻る乗数・最終比較 | \(0\le m\le76\) | \(m\ge77\) は一つの解析的な倍率評価 |
| 外側の左移動回数 \(\ell\) | 上限を設けない | Jacobi 分解、混合項の非負性、重みの平方和を用いる |

小さい \(m\) の証明書は、次数が明示された多項式の Bernstein 基底への厳密変換である。全係数が非負または必要な箇所で厳密に正であることから、パラメータ区間全体の不等式を証明する。

大きな証明書は、完全な JSON を決定的な gzip 形式で保存した。`COMPRESSED_CERTIFICATES.json` に圧縮前後の SHA-256 を記録しており、再現プログラムは展開後の完全な証明書も照合する。証明書内の状態ラベルは生成時点の記録で、最終的な証明範囲と判定は本書・証明本文・監査記録に従う。

## 6. openai/math から何を使ったか

最初に調べた外部資料の中では、Family 169 の「正の構成との厳密な同定を先に行い、その後に係数正性を運ぶ」という設計が役立った。Family 180 の対状態による相殺も、混合項を個別に検討する観点として参考にした。参照した原稿・節・固定 commit は [source_review.md](../source_review.md) にまとめてある。

最初の量子交換子、Lorentzian、Strongly Rayleigh の直接移植では、適用条件の障害または元の問題への循環が残った。その結果を踏まえ、今回は実際の正準差分を Jacobi の正の和へ同定し、混合小行列式と補正の大きさを明示して処理した。

したがって、今回の定理の具体的な数学的依存は、AIMath に既存の folded-kernel・Chebyshev・正規化した余裕の補題と、今回追加した一様評価である。外部原稿に Local TP2 の定理がそのまま載っていたという主張はしていない。

## 7. 次の未解決部分

次は \(L^mR^kL^\ell\) の任意の \(k\ge3\) である。初期の四つの LR 比較は、今回の議論を延ばすと全 \(k\ge2\) にも成立する。これは [ALL_M_INITIAL_COMPARISONS.md](hour_invariant/ALL_M_INITIAL_COMPARISONS.md) 末尾に分けて記録した。

最後の追加探索では、trace に関しても次の補助定理まで進めた。任意の \(m,k\ge0\) と中心 \(C=C_{L^mR^k}\) に対して、

\[
3(x+1)C-x-r,\qquad (x+1)\{3(x+1)C-x-r\}
\]

は、全ての \(r\in[-2,2]\) について少なくとも 1-strong、すなわち各支持添字で \(\delta_n\ge h_n>0\) を満たす。\(m=0\) の境界は、Chebyshev の根を二個ずつ組にして扱い、一般の場合とは別に閉じた。

この補助定理の [本文](hour_transport/ARBITRARY_K_TRACE_EXPLORATORY.md) と [監査記録](hour_invariant/AUDIT_ARBITRARY_K_TRACE.md) を、主定理の依存関係から分けて保存した。有限部分の867個の Bernstein 係数も別実装で一致し、9個の0は強度評価の終端の等号に対応する。多項式自身の必要な defect は厳密に正である。

これで、任意の \(k\ge3\) へ進むための初期 LR 比較と trace の条件は整った。残るのは、新しい初期多項式と中点の混合核、補正を吸収する一様評価である。任意の \(k\) に対する Local TP2 自体の証明は、ここから先の課題として残る。

Mac なら **VS Code の統合ターミナル**で、この `one_hour_20261007` ディレクトリを開いて実行する。

```bash
python3 reproduce.py
```

この再実行が検証するのは有限証明書と厳密計算である。全ての \(m,\ell\) を覆う根拠は、証明本文に書いた帰納と解析的な不等式にある。
