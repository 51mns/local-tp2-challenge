# A common kernel and quantitative reduction for the actual even-index ray comparison

Let `u_r=U_r(x+3/2)`, `V_r=u_r+u_(r-1)`, `W_r=u_r-u_(r-1)`, `T_n=sum_(j=0)^n u_j`, and `y=x+1`.

## Proven common-kernel theorem

For every r>=1, `yV_r` has a folded-TP2 convolution kernel and strictly positive supported defect differences.

Use the root pairing and parameter domains already proved for V_r in `continuation_prefix.md`. Let `f=x²+s x+c`, where

`s=3+u`, `c=5/4+(5/2)u+v`, `u,v in [0,1]`.

The following blocks are strictly in the folded cone, as certified over their whole parameter domains:

| Block | Additional parameter ranges | Lower bounds by supported Fourier index |
|---|---|---|
| `y f g` | f,g independent | `62335/256,176361/256,13491/32,603/4,47/2,1` |
| `y(x+a)` | `3/2<=a<=2` | `2,7/4,1` |
| `y(x+a)(x+b)` | `1<=a<=3/2`, `3/2<=b<=5/2` | `4,14,17/4,1` |
| `y(x+a)f` | `3/2<=a<=2` | `2909/64,6867/64,435/8,14,1` |

The exact rational Bernstein coefficient arrays are generated by the standalone `resumed_external_yV.py` and saved in `resumed_external_yV_certificates.json`.

To prove the infinite theorem, use V_r's established root factorization. According to r modulo 4, reserve respectively: a quartic, the middle linear factor, the innermost quadratic pair, or the middle factor plus one quadratic pair. The needed quartic in the first case exists because r>=4 there. Multiply this residue by y and apply the corresponding block certificate. All remaining factors form the previously proved folded-cone quartic blocks. Strict product closure proves the theorem. The omitted r=0 would give y itself, which is not in the cone.

## Exact comparison to a larger pair

At all-left path length `k=2r-2`, the original smaller difference is

`S=y u_(2r)=y V_r W_r`.

Put

`E=yT_(2r-1)=y u_(r-1)V_r`, `A=2x+1`, `U=u_2=4x²+12x+8`.

For r>=3, the audited W theorem and its correct subtraction identity give

`H(W_r) <_lr H(A u_(r-1))`.

Applying the folded convolution kernel of `yV_r`, now proved above, yields

`H(S) <=_lr H(AE)`.

This uses the correct factor `A=2x+1`; it does not replace that factor by `2y`.

The previously proposed proxy is

`C_proxy=(x+2)B_k=(3/4) U E+K`,

where `B_k=2+2y+3y²T_(k+1)` and `K=2(x+2)²`. Hence proving

`H(AE) <=_lr H((3/4)UE+K)`

would finish the proxy comparison for this family. The comparison in this last display is **not claimed proved in this note**.

## A quantitative propagation lemma for that remaining comparison

For coefficient rows define

`M_n(E)=H(UE)[n+1]H(AE)[n]-H(UE)[n]H(AE)[n+1]`.

Suppose a polynomial R satisfies the full nonnegative MLR comparison `H(AR)<=_lr H(UR)`. If Q is in the folded cone, Cauchy–Binet gives

`M_n(RQ) >= M_n(R) det K_Q[{n,n+1},{n,n+1}]`.

The selected principal kernel minor is at least `delta_Q(0)`. Indeed, for n>=1, the interior folded-minor formula has a=0 and b=2n:

`det=Delta_0-Delta_(2n+1)+h_0 h_(2n+1)(t_(2n+1)-t_0)>=Delta_0-Delta_1=delta_Q(0)`.

The support-boundary version gives the same inequality; n=0 is equality. Therefore if

`delta_Q(0)>=Q(2)`

and `M_n(R)>=c R(2)`, then

`M_n(RQ)>=c (RQ)(2)`.

This applies to the scaled quartic root blocks already certified in `continuation_bracket.md`. Crucially, the full MLR comparison is needed before discarding all other Cauchy–Binet summands.

Finally, `H(K)=(12,8,2)` and `A(2)=5`. Therefore, at n=0,1,2,

`H(K)[n+1]H(AE)[n]-H(K)[n]H(AE)[n+1] >= -5H(K)[n]E(2)`.

At n>=3 this expression is zero. Thus a sufficient finite-residue target is:

- all adjacent M_n(R) are nonnegative;
- `M_0(R)>80R(2)`;
- `M_1(R)>(160/3)R(2)`;
- `M_2(R)>(40/3)R(2)`.

These margins would propagate through the remaining quartic factors and dominate the additive K contribution. Pulling additional quartics into a bounded residue is a possible way to seek such parameter-box certificates. This note proves the propagation and reduction, not the missing residue certificates.
