# 共通条件の初期化と、残る保存命題への直接の進展

**全木の strict Local TP2 は、まだ未証明。今回は、前回未確認だった「最初の左右両方で新しい補助条件が成立すること」を証明し、一般の状態で使える追加の保存則を得た。** 個別経路の件数を全木の証明として扱ってはいない。

GPT-6.1 Sol の六担当で、補助条件の保存、最後の比較、反証、係数表示、厳密なパラメータ証明、独立監査を分担した。監督側でも式・支持範囲・初期例外を確認した。

## 1. 帰納法の出発点がそろった

前回の共通条件は、四つの LR 比較、現在の paired midpoint packet、二つの漸化式の原点記録、最後の strict proxy 比較からなる。根では LR 比較に例外があるため、根を別に処理し、その次から通常の共通条件を使う。

今回、根から short / long のどちらへ進んでも、**両向きの paired midpoint packet 全体が成立すること**を証明した。以前の強い定義である、参照小行列式の4倍を用いる条件まで確認できた。

これは、いくつかのパラメータ点を試した結果ではない。\(r,s\in[-2,2]\) の正方形全体について、正確な有理数の Bernstein 係数による証明を作った。全小行列式への変換、通常・平滑化の両方、支持範囲、次数条件、端の添字も確認した。第一段の LR と proxy は既に証明済みだったので、これで**左右両方の第一段で、通常の共通条件がすべて成立する**。

証明：[quantitative_midpoint_bernstein.md](quantitative_midpoint_bernstein.md)。完全な係数証明は圧縮ファイルにも保存した。

## 2. 無限個の核の小行列式を、正確な係数条件へ置き換えた

多項式 \(f\) に対して、二変数の character 表示を \(T_f=\Phi(f(\xi)f(\zeta))\) と書く。このとき、任意の実多項式 \(f,b\) と実数 \(\gamma\) について

\[
\det K_f[I,J]\ge\gamma\det K_b[I,J]
\quad\text{が全ての順序付き }I,J\text{ で成立}
\]

することと、\(T_f-\gamma T_b\) の全 character 係数が非負であることが同値だと証明した。中央の正規化や、いくらでも大きい核の添字を含む一般定理である。

この変換により、一つの状態における全小行列式の条件を、有限個の係数で正確に表せる。ただし状態の次数は分岐に伴って増えるので、**これだけで全状態を有限回の計算で証明できるわけではない**。

証明：[network_relative_character.md](network_relative_character.md)。独立監査：[falsification_network_audit.md](falsification_network_audit.md)。

## 3. 必要な補助条件をさらに絞った

中点ブロック

\[
H_{r,s}=b_0(T-r)(T-s)+b_1\left(T-\frac{r+s}{2}\right)
\]

に対して、スペクトル混合の証明で本当に必要なのは

\[
T_{H_{r,s}}-\frac{(r-s)^2}{4}T_{b_1}\ge_{\rm char}0
\]

という条件である。以前の一律4倍の条件は十分条件だった。この正確な係数条件、shifted trace の核条件、単一ブロックの厳密な核条件を使う、より弱い補助条件でも原点記録の証明は成立する。

また \(u=(r+s)/2\)、\(w=(r-s)^2/4\) とすると、各 character 係数は \(w\) の二次式になる。その区間内での非負性を、端点と二次式の正確な条件で表した。これは残る命題を扱いやすくする同値変形であり、新しい中心への保存そのものを証明したという意味ではない。

## 4. 一般の左右更新について証明できた部分

**最後の比較に使う \(Q=S-G\) の核は、原点記録から厳密に正となる。** 通常の原点では、境界値1の Robin 型漸化式から導いた。端点1の例外では

\[
y\bigl(U_N((2x+3)/2)-U_{N-1}((2x+3)/2)\bigr),\qquad N\ge2
\]

を扱う追加の証明を作った。四種類のパラメータ領域の厳密な証明と、全ての \(N\) を覆う因数分解を組み合わせたもので、独立監査を通過した。したがって、左右どちらへ進んだ子でも、この \(Q\) の核条件が原点記録から従う。

さらに、新しい逆向き packet の単一ブロックについて、**パラメータ \(-1\) の部分は左右どちらでも保たれる**と証明した。short 側は親の単一ブロックに一致し、long 側は親の漸化式の連続二項の和になる。これは一般の親状態を対象とした保存則だが、全パラメータの packet 保存にはまだ届いていない。

証明：[packet_transport_subgate.md](packet_transport_subgate.md)、[root_boundary_q.md](root_boundary_q.md)、[proxy_robin.md](proxy_robin.md)。

## 5. 最後の比較で本当に残っている範囲

\(P=x+2\)、\(V=PX+P^2C\) とすると

\[
W_n(Q,\Pi)=\delta_n(Q)+W_n(Q,V)
\]

である。今回 \(\delta_n(Q)>0\) を証明したが、第二項は負になることもあるため、これを無視して結論を出してはいけない。

\(V\) の支持より上の添字では第二項が消えるので、そこは自動的に解決する。末端の添字も正と分かる。したがって各状態で残るのは、\(Q\) と \(V\) の係数が重なる範囲の厳密比較である。この範囲を全状態について処理する証明はまだ得られていない。
