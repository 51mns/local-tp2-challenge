# 任意の左右分岐を扱う共通条件：今回の到達点

**全木の strict Local TP2 は未証明。今回の主成果は、状態に二つの漸化式の証明記録を追加することで、残る解析的な保存命題を二種類に整理したこと。二つの命題そのものはまだ証明できていない。**

個別の経路の追加を完成とは数えない。判定基準は、初期状態で成立し、左右どちらの更新でも保たれ、目標を導く一つの共通条件が得られたかどうかである。

## 1. 共通条件の新しい形

以下の short / long は次数の小さい端点・大きい端点を残す更新であり、固定された Farey の L / R 記号とは区別する。どちらを任意の順番で選んでも扱えることが必要である。

前回の条件 \(P_Q\) は、四つの LR 比較、核 \(K_G,K_M\) の TP2、最後の strict proxy 比較からなっていた。四つの LR 比較は、親の \(P_Q\) から両方の子へ保存されることが既に証明されている。

今回、各端点に、その端点を固定した漸化式の初期値と添字を記録する。固定した原点データ \((\tau,b_0,b_1)\) に対し

\[
f_j=b_0U_j(\tau/2)+b_1U_{j-1}(\tau/2),\qquad U_{-1}=0
\]

とする。状態に保存する等式は次の二組である。

| 記録する端点 | 一つ前の項 | 現在の項 | 添字条件 |
| --- | --- | --- | --- |
| 小さい端点 \(X\) | \(f_{N_X-1}=g\) | \(f_{N_X}=s\) | \(N_X\ge2\) |
| 大きい端点 \(Y\) | \(f_{N_Y-1}=e+g\) | \(f_{N_Y}=s+d\) | \(N_Y\ge1\) |

一つ前の項も必要であり、現在の項だけの一致では不十分である。端点を残す更新では添字を一つ増やす。新しい端点を作る更新では、親の現在の補助条件から新しい記録を初期化する。この規則を short / long の両方について恒等式で証明した。

必要な補助条件は、中心 \(T=M-1\)、\(c_A=e+g+s\) に対する二つの midpoint packet

\[
\operatorname{MP}_2(T,c_A,e),\qquad
\operatorname{MP}_2(T,e,c_A)
\]

である。これは、以前の三つの独立パラメータを持つ packet のうち、証明で実際に使う中点 \(u=(r+s)/2\) に絞った条件である。厳密な定義、全小行列式の条件、支持範囲と平滑化の条件は [packet_transport.md](packet_transport.md) に記載した。

この原点証明と \(N_X\ge2\) から、現在の \(G=yf_{N_X-1}\) の核条件が従う。また、現在の packet の shifted trace 条件で \(\rho=-1\) を選べば、\(T+1=M\) の核条件が従う。したがって、拡張状態には \(K_G,K_M\) を独立の未解決条件として置く必要がなくなった。

原点を記録する方法は、将来の全状態で目標が成立すると仮定していない。記録する多項式と添字は有限個である。ただし packet の定義自体は連続パラメータと全小行列式にわたる解析的な条件であり、有限回の数値検査で済むという意味ではない。

## 2. 残る二つの保存命題

通常状態の共通条件を、四つの LR 比較・現在の二つの \(\operatorname{MP}_2\)・二つの原点記録・strict proxy 比較の組とする。根は四つの LR 比較の例外なので、既に証明した根の目標と第一段の LR / proxy を使う明示的な根の分岐を付ける。最終的な述語と帰納法の義務は [packet_expanded_predicate.md](packet_expanded_predicate.md) に明記した。

| 残る命題 | 正確な課題 |
| --- | --- |
| A：現在の packet の保存 | この拡張状態から、short / long の**新しい中心と種**に対する二つの \(\operatorname{MP}_2\) を導く。根から第一段への packet 保存もここに含む。 |
| B：strict proxy の保存 | 通常の拡張状態から、short / long の両方で \(W_n(Q',\Pi')>0\) を全支持添字について導く。根から第一段の proxy は既存の厳密な初期確認で処理する。 |

この二命題が得られれば、記録の保存と既知の LR 保存を組み合わせた帰納法で、任意の有限分岐列をまとめて扱える。現時点では **A も B も OPEN**。第一段の元の \(P_Q\) が成立することから、第一段の新しい packet まで成立すると読み替えてはいけない。

したがって「あと何回の証明が必要か」への回答は、**この構成では主要な未解決命題は二種類。ただし必要な補題の数、試行回数、完成までの期間は不明**である。仮定を強くした条件付き整理なので、作業量が三分の二になったという主張でもない。

## 3. 独立に得られた補助結果

- **曲率ペアの両子保存。** 親の \(P_Q\) を仮定すれば、二つの bivariate curvature の非負性が short / long の両方へ保存される。第一段の全係数による初期確認と独立監査を通過した。この条件は共通状態へ追加できるが、それだけから子の proxy や目標はまだ導けない。
- **shifted trace の範囲拡大。** 明示した係数条件の下で \(|\rho|\le5/2\) の核正性を証明した。これにより Robin 型の純粋な伝播因子を任意の長さで扱える。係数条件自体の両子保存は未証明である。
- **固定原点からの中点ブロック伝播。** \(\operatorname{MP}_{5/2}\) を原点に仮定すれば、固定端点を任意回進めた \([-2,2]\) の単一・中点ブロックの核条件が従う。移動後の参照小行列式との相対評価や、新しい中心の packet 保存はこの定理に含まれない。
- **乗数条件の局所化。** \(C\) の核条件、最初の三つの局所評価と一つの中心不等式 \(B_0\ge0\) から、\(K_M\) と中心比較を導ける。これらの仮定の両子保存は未証明である。

詳細と独立監査は `proxy_*`、`gap_*`、`multiplier_*`、`center_*` に保存した。整数・有理数の再現計算は、恒等式と有限個の初期例・反例の確認に使用し、全木の帰納法の代用にはしていない。

## 4. 捨てるべき近道も明確になった

実際の first-short 状態で曲率は非負だが、Cassini 式の符号付き補正の境界は

\[
(-245,\ 43,\ -44,\ 48)
\]

となる。「曲率が非負なら補正も項ごとに非負」という推論は、正準状態そのもので失敗する。同じ状態の実際の gap の defect は \((192,256,112,16)\) で正である。これは目標の反例ではなく、相殺を無視する証明法の反例である。

また、独立パラメータを持つ強すぎる packet の抽象的な保存反例は得たが、必要な中点条件や正準状態への反例ではない。通常係数が正の Fricke 解の分類も整理した。整数 Laurent 解の変異木による分類は Bittmann らの [arXiv:2602.14802v1, Proposition 2.3](https://arxiv.org/html/2602.14802v1#S2.SS1) にある既存結果であり、今回の整理をその場合の新発見とは扱わない。
