# 任意の左右に共通する条件：今回の結果

**全木の厳密 Local TP2 は未証明。左右どちらへ進んでも保たれる、十分な共通条件の完成には至っていない。**

今回は個別経路の証明を追加することを主目的にせず、状態の有限個の条件から元の目標を導き、その条件を左右へ移す方針を調べた。得られた主結果は、**四つの係数の比の比較を左右両方へ移す共通の帰納法**と、その帰納法が依存する**三つの未解決の解析的条件**の明確化である。ここでの「三つ」は、残りの作業が簡単な証明三本で終わるという意味ではない。

## 1. 共通条件のどこまで証明したか

次数順の端点を `X,Y`、中心を `C`、`y=x+1`、`P=x+2` とする。実際の多項式差を

```
E=Y-X, G=C-Y, R=yr,
t=3yX-x, M=3yC-x+1,
S=tG-R, D=EM
```

と書く。`r` は既存の正規化状態の座標である。`S` は小さい子と中心との差、`D` は二つの子の差なので、元の目標は `H(S)` と `H(D)` の厳密な隣接小行列式の正値性である。

新しい比較用の多項式は

```
Q=S-G=(t-2)C-xX,
Π=XPM=PQ+V,
V=PX+P²C.
```

このとき最後の比較は正確に

```
W_n(Q,Π)=δ_n(Q)+W_n(Q,V)
```

となる。別々に扱うと負になる項を、この一つの式に残す。

通常の状態に課す四つの比較は

```
E <=lr G,  R <=lr G,  XP <=lr E,  YP <=lr G.
```

さらに次の三条件を仮定する。

| 条件 | 役割 | 左右への保存 |
|---|---|---|
| `G` の折り畳み核が TP2 | 多項式を掛けた比較を移す | **未証明** |
| `M` の折り畳み核が TP2 | `XP<=lr E` から最後の比較へ移す | **未証明** |
| `δ_n(Q)+W_n(Q,V)>0` | 厳密性を与える | **未証明** |

これらが親の状態で成り立てば、

```
S <=lr Q <lr Π <=lr D
```

が得られ、元の Local TP2 が従う。末端添字も次数と正の台によって処理した。さらに、四つの比較は**左右のどちらの子にも保存される**。子の Local TP2 を仮定して親の結論を導く循環はない。

根では最初の二つの比較が偽なので、根を明示的な例外として扱う。根の目標と、最初の二つの子が通常の全条件を満たすことは、厳密な整数で確認した。したがって、上表の三条件の左右保存を証明できれば、この共通条件による全木の帰納法が完成する。

この部分の本文は `reduction_common.md`。`network_reduction_audit.md` と独立実装が、恒等式・根と最初の子・比較の向き・中央と末端・両方の更新を監査した。判定はこの限定した補題について **PROVED_INTERNAL**。同じセッションのモデルによる内部監査であり、外部査読や形式証明ではない。

## 2. 実際の木で破れた候補

ここでは `s` を次数の小さい子への移動、`l` を大きい子への移動とする。固定された Farey の L/R の文字とは区別する。

| 候補 | 確定した障害 |
|---|---|
| 全支持区間での強さと係数支配率を掛ける十分条件 | 平滑化ありで `s³`、なしで `s⁴` に失敗。さらに無限に多くの実際の状態で失敗する一般証明を得た |
| 参照多項式の次数に限定した強さの十分条件 | 改良版でも平滑化あり `s⁶`、なし `s⁷` に失敗 |
| 減算の正の剰余の一定割合 `1/32` を一様に確保する条件 | 平滑化した中心では `s²⁸`、平滑化なしでは `s²⁹` に失敗 |
| 行列の外積展開を各項ごとに非負にする条件 | 実際の根からの遷移で負の寄与 `−72`。合計の小行列式は `+271` なので、相殺を残す必要がある |
| 符号を持つ種を常に正として扱う条件 | 補助量 `eta=e-r` は、小さい子で `+e`、大きい子で `−e` へ更新される |

これらは**Local TP2への反例ではない**。証明に使おうとした強すぎる条件や、必要な相殺を捨てた方法への反例である。とくに、強さによる十分条件の失敗と、目的の小行列式の支配そのものの失敗は区別した。

## 3. 次に使える補助構造と、その限界

`invariant_spectral_packet.md` は、どの状態でも成立する二種類の符号を持つ初期値と Cassini 型の恒等式を整理した。条件付きで全ての固定端点の段数を扱えるが、端点を変えた後も条件が保たれることは未証明である。同じ端点で一段進む場合でさえ、従来のパラメータ区間をそのまま使えるとは限らない。

左右の子を組にして扱うと、両方の大きい端点は古い中心 `C` なので、共通の `T=3yC-x` が使える。正規化した `s=S/y,d=D/y` に対し、初期値を

```
c_A=e+g+s,  c_B=g+s+d
```

とすると、`c_B=c_A+Te` が恒等的に成り立つ。さらに通常の係数の順序で **`0<=c_A<=Te<=c_B<=2Te` が全木で成立する**。これは有限検査の観察ではなく、根と両方の更新を扱う証明である。左右の符号の違いを同じ初期値の組へ書き直せるが、この係数の上界から折り畳み核の TP2 はまだ導けない。

この組を正順と逆順で使う二つの条件を、新たな共通候補として定式化した。根では、前回までに証明した二種類の補題へ正確に対応する。逆順では初期値の次数が大きくなるため、従来の条件をそのまま適用せず、次数の条件と `N>=1` の適用範囲を証明し直した。この候補の左右保存と、共通条件全体への連結は未証明である。`pair_switch_audit.md` に独立監査を記録する。

`invariant_shifted_trace_lemma.md` では、正規化した端点 `a` の強さと平滑化した核についての明示的な条件から、全ての実数 `rho∈[-2,2]` に対する `3y²a+2x+3-rho` の厳密な核条件を証明した。中央・末端・低次数の例外を独立監査した。ただし `a` が `a+e` へ変わる更新で、仮定が保たれるかは未証明である。

`pair_*` は、上の厳密な比較式と、左右で増える部分を符号付きのまま記録する。有限検査で増分が非負でも、全状態で非負である証明の代わりにはしない。

`quantitative_*` は、減算・和の支持区間境界・端点側の強さについての十分条件を扱う。成立した補題と、実際の木では満たされない仮定を分ける。詳細な監査状況は各報告と `MANIFEST.json` に記録する。

`gate_audit.md` は、上の共通条件を満たしていても、補助的に使いたい端点や `t` の核条件まで自動的に従うわけではないことを、正確な有理数の例で示す。この例は Fricke 関係を満たさず、実際の木の反例でも、共通条件の保存への反例でもない。証明の途中で追加の仮定を暗黙に使わないための監査結果である。

## 4. 検査の位置づけ

元の再帰と正規化再帰を別々に実装し、中央の反射、支持区間、Fricke/Cassini の関係も確認した。直接の相対小行列式は44状態・指定した行列添字範囲の3,109,051比較で失敗がなかったが、**これは無限の行列全体や全木の証明ではない**。

共通条件そのものは、実際の状態と、Frickeを外した有限個の抽象的状態の両方で検査した。抽象的状態の数値的成功や失敗は、正準状態の証明・反例とは区別する。正確な対象、最初の失敗、全多項式、再現コードは `falsification_report.md` と付属JSONにある。

## 5. 今後の判定基準

次に全木への前進と認定するのは、上の三条件のいずれかの左右保存を証明すること、それらを同時に保証するよりよい条件を作ること、または実際の反例によって候補を修正することである。経路の種類や検査件数が増えただけでは、全体証明への前進と同一視しない。
