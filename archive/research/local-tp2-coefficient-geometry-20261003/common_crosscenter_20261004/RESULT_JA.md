# 任意の左右更新で保たれる部分と、残る比較の整理

**全木の strict Local TP2 は、まだ未証明。** 今回は GPT-6.1 Sol を6並列で使い、一般の親状態から左右どちらへ進んでも成立する条件を追加で証明した。有限個の経路が通ったことを全木の証明にはしていない。

## 今回証明した共通の保存則

親が現在の共通条件を満たすと仮定したとき、次が左右両方の子で成立する。

- **補助条件で使う多項式の正の係数範囲と次数条件。** これらは正準状態の式と既存の原点記録から従い、新たに子の補助条件を仮定する必要がない。
- **すべてのパラメータに対する、trace の中央の厳密不等式。** 更新式 `T'=T+3y²v` と、中央の条件が加算で保たれることを使った。通常の状態と端点1の例外をともに扱っている。
- **trace の上側の係数範囲の厳密不等式。** 親の次数より十分上では、追加された項だけの不等式になる。境界の一部も、負の交差項を正の項が上回ることまで証明した。
- **逆向きの単一ブロックの上側の厳密不等式。** 以前証明したパラメータ −1 の式を基準にすると、他のパラメータで変わる範囲は低い添字に限られる。
- **混合条件の最も外側の係数。** 左右・両向き・通常／平滑化のすべてで、全パラメータにわたる厳密な正性を証明した。内側の係数の比較は残る。

trace の中央の証明は [root_central_trace.md](root_central_trace.md)、上側の比較は [packet_spectral.md](packet_spectral.md)、単一ブロックは [packet_algebra.md](packet_algebra.md) にある。

中央条件には、証明済みの原点記録を持つ経路に沿って、全パラメータ共通の下限 `185` も得た。これは他の保存条件を不要にするものではない。

さらに、中心を「固定された初期項」と「厳密な核条件を満たす漸化式の和」に分ける式を、左右両方の原点の更新について証明した。これにより、trace の未処理範囲を、原点を維持して進む長さに依存しない低い添字の範囲へ絞れる。ただし原点を切り替えた際の初期項との比較は残る。詳細は [proxy_algebra.md](proxy_algebra.md)。

## 最後の比較に使う条件を弱めた

これまでの十分条件は、補助的な行 `Π` を使う `Q < Π` だった。今回、**実際の行 `D` に対する `Q < D` でも、目標と四つの LR 条件の両子保存が成立する**ことを確認した。

理由は、既に導ける `S ≤ Q` と合わせて `S ≤ Q < D` となるため。古い条件から新しい条件は従うが、証明の依存関係は新しい条件から直接組み直した。根と最初の両子では成立する。**新しい条件自体が一般の左右更新で保たれることは、まだ未証明**である。

この変更により、今後は `Q < D` の保存を直接狙える。旧方式の証明済み部分も引き続き使える。証明と定量的な評価は [proxy_character.md](proxy_character.md)、独立監査は [audit_gate_reduction.md](audit_gate_reduction.md) にある。

## 使えない近道も特定した

交差項を一つずつ非負にしようとする方針には、実際の正準状態でも必ず負になる項がある。最初の左右の子は補助条件全体が成立すると既に証明済みなので、これは目標への反例ではない。**正の項との打ち消し合いを保ったまま比較する必要がある**ことを示している。

また、正準状態の制約を外すと、親の paired packet 全体が連続パラメータの全域で成立していても、子で失敗する例を厳密に構成できた。Fricke 関係、通常係数の正性、原点のつながりを落として証明を簡単にすることはできない。

追加した定量的な下界にも、実際の最初の子で不足するものがあった。成立しない十分条件を次の帰納法の仮定として採用することはしていない。

## 残る二種類の命題

| 命題 | 今回絞れた範囲 | 未証明の部分 |
| --- | --- | --- |
| 新しい中心の補助条件の両子保存 | 支持・次数、trace の中央と上側、逆向き単一ブロックの上側を処理 | trace の重なり範囲、単一ブロックの残る範囲、正負の交差項を合わせた全体の比較 |
| 最後の比較の両子保存 | 十分条件を `Q < D` まで弱められた。原点からの厳密な式と定量的な下界を整理 | `Q < D` を任意の親から左右両方へ運ぶ証明。旧方式の `Q < Π` の重なり範囲も未解決 |

次の焦点は、正準状態の制約を使って**負の交差項を吸収する定量的な評価を得ること**。さらに経路を数えることや、補助条件を言い換えるだけでは、完成とは扱わない。

証明と反例の範囲を独立監査し、正確な整数・有理数の検証コードとともに保存した。元の成果の保存基点は private `51mns/AIMath` の `27d40e30658de83fe0ba896de2ec319072b44e21`。`AIMath-public/main` の確認時点の head は `6e770f3b3e3f26af5df5308572917559343b68f4` で、前回から変わっていなかった。
